# The Affiliates Partners — этап 14/14: итог локальной разработки

**Дата:** 20.11.2026. **Ветка:** `feature/green-theme-20261114`. **Режим:** локально, без публикации.

## Закрытый объём разработки

Этапы 1–14 выполнены как отдельные локальные изменения: графитово-янтарная система Rounded Float/Amber v3.2, мобильный кабинет с четырьмя вкладками, административные разделы, офферы и назначения, регистрация/возраст/кредитная анкета, шифрованные ФИО/ИНН, ручные стадии и доказательства, проверенные финансовые начисления/вывод, рефералы 15% только от оплаченного вознаграждения, отдельный B-ID блогера, Telegram outbox, статистика без смешивания с реальным балансом, черновые юридические документы, release preflight и финальная процедура приёмки.

В этапе 14 добавлены:

- `tools/stage14_acceptance.py` — независимый read-only отчёт по финальным локальным контрактам, чистоте Git и внешним блокерам, `--require-ready` для fail-closed контроля. Скрипт **ничего не развёртывает**.
- `tests/test_stage14_acceptance.py` — адресные проверки, в том числе запрет считать грязный Git и открытые блокеры успешным релизом.
- `docs/FINAL_RELEASE_RUNBOOK_STAGE14.md` — порядок проверки, раздельного backend/static cutover, резервирования, rollback и фиксации результатов.

- `python -m tools.stage13_preflight` и `python -m tools.stage14_acceptance` — проверка локальных контрактов, **не доказательство** юридической или production готовности.

## Открытые условия публичного запуска

1. Юридическое утверждение оператора, пяти редакций документов, сроков хранения, прав несовершеннолетних, выплат и рекламных договоров. Документы остаются проектами; сборка публичного пакета запрещена.
2. Испытания на отдельной PostgreSQL: миграции, runtime GRANT, изоляция `partners` от CRM, восстановление из бэкапа. Не использовать production DB для тестов.
3. Реальная приёмка iOS/Android Telegram WebView, HMAC, webhook, очереди уведомлений и пользовательских сценариев.
4. Проверенный перед cutover backup/restore, совместимость сервисов и подтверждение отключения legacy auto-deploy.
5. **Отдельное согласие владельца** на GitHub push, затем на Aeza deploy. Завершение 14/14 не даёт такого согласия автоматически.
