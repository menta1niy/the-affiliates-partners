# Этап 11/14 — четвёртая вкладка «Статистика» (локально)

## Функциональность

В Mini App для подтверждённого участника добавлена четвёртая иконка в плавающую мобильную навигацию: «Статистика». Состояния, заголовки и доступность секций согласованы с остальными экранами. Ключевые финансовые значения выделены янтарным акцентом, остальные суммы — нейтральные.

Серверный авторизованный `POST /api/statistics/overview` (внутри Mini App `/statistics/overview`) вычисляет значения только для текущего пользователя — Telegram ID из проверенного initData. Переданный клиентом `user_id` игнорируется.

| Показатель | Источник | Ограничение |
| --- | --- | --- |
| Ещё не в работе | Текущие ставки назначенных активных офферов на стадии `assigned` | Только потенциальный доход |
| В работе / на проверке | Стадии `in_progress` + `submitted` | Только потенциальный доход |
| Завершено / ожидает подтверждения | Стадия `completed` без подтверждённого финансового начисления по офферу | Не банковский hold и не баланс |
| Доступно к запросу | Финансовый реестр (`finance._balances`) | Реально подтверждённые средства за вычетом выплат и резерва |
| Зарезервировано | Реестр запросов `pending` и `confirmed` | Нельзя повторно запросить |
| Выплачено | Реестр выплат `paid` | Только подтверждённые фактические платежи |
| Начислено за всё время | Реестр начислений плюс реферальный журнал | Не включает потенциальные ставки |

Если по офферу есть хотя бы одно подтверждённое финансовое начисление, его ставка целиком исключается из потенциальных карточек: исключает визуальное двойное отображение, но не моделирует частичные конверсии. Текущие ставки назначенных офферов — ориентир, не исторический снимок тарифа и не обещание оплаты. Отклонённые назначения не прибавляют потенциальный доход. Отключённые офферы не показываются в потенциальных значениях. Профиль по-прежнему содержит запрос выплаты и детальную историю.
