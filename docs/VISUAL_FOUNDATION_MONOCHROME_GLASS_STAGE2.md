# The Affiliates Partners — Visual Foundation, этап 2

**Основа:** `docs/DESIGN_AUDIT_MONOCHROME_GLASS_STAGE1.md`.

**Область изменений:** только локальные HTML/CSS/JS представления и проверка визуальных токенов. Нет правок backend, схемы данных, API-контрактов, структуры экранов или навигационных сценариев. Production не развёрнут.

## 1. Утверждённое визуальное направление

**Black Graphite × Frosted White Glass × Soft White Luminescence.** Основной фон почти чёрный, карточки графитовые, акцент чисто белый. Белые заливки используются выборочно для важных действий; графитовые стеклянные поверхности — для информации и вспомогательных действий. Цветовая идентичность зелёной версии полностью исключена из UI-ресурсов.

### Матовое стекло и подсветка

| Токен | Значение/смысл |
| --- | --- |
| `--glass-quiet` | `rgba(255,255,255,.028)`; вторичные интерактивные слои |
| `--glass-functional` | `rgba(255,255,255,.045)`; базовая панель |
| `--glass-emphasis` | `rgba(255,255,255,.075)`; выбранный элемент |
| `--glass-border` | `rgba(255,255,255,.12)`; единая граница |
| `--glass-edge` | `rgba(255,255,255,.14)`; дополнительный световой край для этапа 3 |
| `--glass-blur` | `12px`; ограниченный blur только для небольших элементов |
| `--glow-edge` | слабая внутренняя засветка верхней кромки |
| `--glow-ambient` | крайне слабый белый рассеянный свет |
| `--glow-cta` | два мягких белых ореола белой CTA |
| `--shadow-panel` | тёмная тень для разделения слоёв |

Не использовать одновременно интенсивный blur, непрозрачный белый фон и яркий glow. Стекло не должно замутнять содержимое. В `prefers-reduced-transparency: reduce` и при отсутствии поддержки backdrop-filter остаётся читаемая графитовая поверхность.

### Типографика и геометрия

- Основной шрифт и display: **Plus Jakarta Sans** с fallback на Inter/system-ui. Загружаются веса 400, 500, 600, 700, 800. Заголовки 800, текст 400; числовые KPI используют `tabular-nums`.
- Шкала расстояний: `--space-1` до `--space-16` (4, 8, 12, 16, 20, 24, 32, 40, 48, 64 px).
- `--radius-card:16px`, `--radius-control:12px`.
- Сохранены действующие размеры, DOM-селекторы и компоновка. Перенос их на новые компоненты — **этап 3**.

## 3. Что изменено локально

- `web/style.css`: старые зелёные override-слои заменены единым foundation-блоком; сохранены геометрия, таблицы, медиа-правила и функциональные стили.
- `web/index.html` и `web/admin/index.html`: `meta theme-color` → `#080909`.
- `web/telegram-layout.js`: Telegram header/background/bottom bar → `#080909`; оставлена прежняя safe-area логика.
- `web/app.js` и `web/admin/admin.js`: только UI-константа цвета шапки Telegram.
- Inline-зелёные фон/бордер из `#participant-detail` и динамического диалога каталога удалены, чтобы общая тема могла управлять их цветом. Размеры/поведение диалогов оставлены прежними.
- `tests/test_visual_foundation.py`: Chromium проверяет фактически вычисленные токены, фон основной CTA, шрифт и theme-color в обоих документах на ширинах 320/390/1440 px. Дополнительная MVP browser regression проверяет неизменность основных действий.

## 5. Критерий завершения этапа

Фундамент дизайна согласован: нет зеленых UI-цветов, есть единые токены белой стеклянной темы, Telegram системная рамка сочетается с фоном, существующие сценарии не изменены. Новый frontend пока **локальный**; заявлять о развёртывании нельзя.
