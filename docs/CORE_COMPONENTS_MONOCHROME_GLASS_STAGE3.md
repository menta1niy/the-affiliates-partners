## Компонентный контракт

| Компонент | CSS / DOM | Внешний вид | Состояния и ограничения |
| --- | --- | --- | --- |
| Primary CTA | `.btn.primary` | Белая заливка, тёмный текст, мягкое двойное свечение | hover только на устройстве с курсором, pressed-сдвиг 1 px, disabled приглушённый, focus-visible белый |
| Secondary / Ghost | `.btn.ghost` | Графитовая поверхность с лёгкой белой стеклянной границей | hover усиливает границу, никакой конкурирующей белой заливки |
| Destructive | `.btn.danger` | Тёмная прозрачная поверхность, пунктирная белая граница | Отделён от Primary без обязательного красного; подтверждения уже предусмотрены существующей JS-логикой |
| KPI | `.metric` | Графитовая карточка, мягкий верхний световой край | tabular-nums, читаемые подписи, существующие размеры |
| Карточки | `.panel`, `.offer-item`, `.participant-detail-item`, `.owner-preview-card` | Низкая прозрачность, тёмный графит, тонкая белая граница | focus-within усиливает контур, overflow-wrap предотвращает выход текста |
| Fields | `input`, `select`, `textarea` | Одинаковые высоты и радиусы, контрастная графитовая основа | focus, readonly, disabled, aria-invalid; textarea допускает изменение высоты |
| Status chip | `.tag`, `.pill`, `.owner-preview-status` | Компактные монохромные метки | active — сплошная граница, pending — пунктир, rejected/blocked — двойная; текст обязателен |
| Tabs | `.admin-tabs` / `aria-selected` | Нейтральный графит и светлая активная граница | Выбранная вкладка имеет `aria-selected=true`, без яркой заливки |
| Dialog | `dialog`, `#participant-detail`, `#mvp-catalog-dialog` | Единая матовая панель, тёмный overlay | ограниченная высота, внутренняя прокрутка, поддержка мобильной ширины |
| Notices | `.message`, `.message.error`, `.empty` | Нейтральные поверхности, текстовая семантика | ошибка отличается пунктирной границей, не только цветом |

Все размеры и эффекты берутся из ранее определённых токенов, а не из индивидуальных значений каждого экрана. Добавлены `--control-height`, `--control-height-compact`, `--control-duration`, `--control-ease`, `--divider`, `--glass-stroke`, `--glass-stroke-active`.

## Влияние на административные кнопки

В `web/admin/admin.js` существующий JS-хелпер `action` принимает **необязательный** третий параметр оформления: `ghost` (по умолчанию), `primary` или `danger`. Сами callback-функции, их API-запросы, разрешения и подтверждения не менялись.

- «Сохранить статус» и «Назначить оффер» помечены `primary`.
- «Убрать оффер» помечен `danger`, существующий `window.confirm` сохранён.
- Все прочие существующие кнопки без изменений остаются `ghost`.

Это презентационный параметр; сервер по-прежнему решает, разрешено ли действие.

## Ограничения производительности и доступности

- Никакого массового `backdrop-filter` на крупных карточках. Для тёмных панелей используется статический полупрозрачный gradient.
- Белое свечение только у основных кнопок; дополнительная подсветка на верхнем крае у информационных панелей.
- `prefers-reduced-transparency` отключает стеклянный эффект на мелких поверхностях и диалогах.
- `prefers-reduced-motion` отключает CSS-переходы и сдвиг кнопки.
- Таблицы, поисковые фильтры и расположение навигации пока остаются прежними — это задачи этапов 5–6.
- Сохранены семантические HTML-кнопки, keyboard focus, контрастный текст и статусы с явным текстом.
- При ошибке или недоступности сети исходные JS-сообщения продолжают работать; новых сетевых обработчиков не добавлено.
