# The Affiliates Partners — этап 4/14: ручные массовые назначения

Реализовано локально по мастер-плану v3.2. Публикация и изменения
production-базы отложены до окончания всех этапов.

## Два режима админ-панели

1. **Оффер → лидам:** выбрать один активный оффер, отметить нескольких
   активных лидов или рефереров в поисковой выдаче.
2. **Лиду → офферы:** выбрать одного активного лида или реферера,
   отметить несколько активных офферов из каталога.

Поиск лида поддерживает имя, username, Telegram ID, внутренний ID.
Фильтры: роль lead/referrer; название и категория оффера. Owner/admin
управляют офферами в разрешённом скоупе, staff не получает новых прав.

**«Выбрать все»** выбирает результаты с текущими фильтрами: до 50
участников на странице или все показанные активные офферы. Выбор
сохраняется при переходе между страницами и фильтрами. «Очистить выбор»
снимает выборку текущего режима. При смене основного оффера или целевого
лида зависимая выборка сбрасывается. Лимит — 200 пар на операцию.

## API и транзакционность

- POST /api/admin/mvp/assignment-candidates: page, query, role_filter
  (all/lead/referrer); активные участники, 50 на страницу, tenant scope.
- POST /api/admin/mvp/bulk-assignment поддерживает mode=offer_to_leads
  с offer_id и user_ids либо mode=lead_to_offers с user_id и offer_ids.
  Дополнительное поле preview=true даёт предварительный расчёт без записи.
- Ответ: requested, to_create, already_assigned, created, preview.
- Во время commit сервер заново проверяет все ID, права и актуальность
  состояний. Ошибка одного элемента отменяет всю группу.
- Дубли в запросе учитываются один раз. Существующие назначения,
  их стадии и комментарии не перезаписываются: только
  INSERT ON CONFLICT DO NOTHING в одной транзакции.
- В аудит записываются исключительно новые назначения; повторная
  отправка не создаёт дубликатов. Для preview побочных эффектов нет.
- Снятие отдельного назначения и ручной статус остаются в карточке лида.
  Массовое снятие, автоназначение и подтверждение банковских результатов
  не входят в этап 4.

## Мобильный UI

- Компактная Amber Edition панель с двумя переключаемыми режимами.
- Поиск и фильтры, выбор всей строки, минимум 44–59 px на интерактивные
  элементы, подсчёт выбранного и явная очистка.
- Перед commit отображается модальный экран: выбрано / новых /
  уже назначено. При отсутствии новых кнопка сохранения отключается.
- Результаты и ошибки доступны в live region. Нет горизонтальной
  прокрутки документа при 320/390 px; модалка укладывается в viewport.
