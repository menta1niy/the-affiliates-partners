Основные правила участия

Аккаунт активируется автоматически после принятия условий. Все опубликованные офферы доступны сразу. Для МФО действует отдельный порядок согласования. Вознаграждения начисляются после проверки результата.

Документы для ознакомления (проекты до утверждения): Политика обработки данных, Согласие на обработку, Условия участия, Реферальная программа. Версия: —.

Юридические тексты находятся на утверждении. До публичного релиза необходимо определить оператора данных, реквизиты, сроки хранения и новую версию согласий.
